# Bhoomikkoru Bharam (ഭൂമിക്കൊരു ഭാരം)
> **“A completely unnecessary experience.”**
> *“We spent several hours building this so that you can spend several minutes accomplishing nothing.”*

A hyper-polished web application intentionally designed to be extremely frustrating, unnecessarily complicated, unpredictable, and completely useless. Completing a simple **Sign Up → Login** process requires an absurd amount of time, patience, and sanity.

---

## 🌀 Features

1. **Mock-Government Bureaucratic Identity**:
   - Institutional warm ivory paper theme (`#faf9f5`), double borders, rubber stamps (`VOID • DO NOT ENTER`), and high-contrast typography.
   - Tagline: *“Department of Redundant Digital Processes • Form BB-2026/VOID”*.

2. **Phase-by-Phase Segregation**:
   - **Phase 01 (Name)**: Real-time typo chaos (~3 visual typos injected while typing), text disappearing bug (text turns invisible for 1.8s while still internally present), moving input container (drifts 15–20px periodically), and random resets.
   - **Intermediate Void**: Intentionally blank screen that silently evaporates stamina quota down to 10%.
   - **Phase 02 (Phone)**: No keyboard input allowed. Digit assembly requires scrolling through a microscopic 3px scrollbar tape. Backspace occasionally deletes two digits by accident.
   - **Phase 03 (Gender)**: Radio buttons periodically shuffle and swap positions. Includes unwanted options like *Walmart Shopping Bag (20L)*, *AH-64 Apache Helicopter*, *Microwave Oven (800W)*, and *Quantum Entangled Cat*.
   - **Phase 04 (Password)**: Reversed visibility logic (**Eye Open** = Hidden, **Eye Closed** = Visible). Tooltip: *“Maamanodonnum thonnalle.”*
   - **Phase 05 (Confirmation)**: Blocks progression unless Stamina Quota reaches required threshold.

3. **Timer-Controlled Annoyance Fan System**:
   - **10s Active $\leftrightarrow$ 40s Frozen** cycle running continuously across the entire app.
   - During the 40s freeze: mouse pointer events, typing, and scrolling are globally revoked with rotating sarcastic commentary.
   - Manual **TURN FAN OFF** button only keeps the fan off for 5 seconds before automatically turning back on.

4. **Advertisement & Stamina System**:
   - **10-Question Math Qualification Exam**: Features trick/inverted rules (*“Select an INCORRECT answer”*). Any mistake disqualifies you.
   - **60-Second Unskippable Countdown**: With dynamic passive-aggressive updates every 10 seconds.
   - **Satirical Ads**: Commercial promotion for *Nothing™* ($999/mo) and *Digital Stone™ Pro*.

5. **Login Gateway & Catastrophic Crash**:
   - Initial 4 login attempts fail with snarky rejection reasons (*“Authentication failed. Reason: Yes.”*).
   - Attempt 5 triggers a celebratory confetti explosion for 1.5 seconds, followed immediately by a dramatic simulated system crash screen (`000_USELESS`).
   - Clicking **RESTART MY SUFFERING** wipes session storage and resets the nightmare from the beginning.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm or yarn

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/Cathy-18/Bhoomikoru-Bharam.git
cd Bhoomikoru-Bharam

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
